# Triage 标签

技能以五个规范 triage 角色说话。本文件把这些角色映射到本仓库 issue tracker 里实际使用的标签字符串。

| 技能中的标签 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估该议题 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整指定，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不予处理 |

当技能提到某个角色（例如「apply the AFK-ready triage label」）时，使用表中对应的本仓库标签字符串。

本仓库用默认词汇，左右两列同名，没有映射歧义。要换叫法就改右列 —— 改完这里，`triage` 会跟着用你的词。
